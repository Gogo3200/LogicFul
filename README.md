# LogicFul
LogicFul is a datapack that makes Minecraft into a logic gate simulator using wool blocks and carpets.

## Note
This datapack is meant for creative players who want to build with logic gates. This is not recommended to play in survival (you *can* play it in survival, but you'd get nothing out of it). There are many limitations to this system where vanilla versions of logic gates could outpace it. If you don't like these limitations, move onto redstone or something.

## Supported Versions
* 26.2

## How to Install
1. Create a new world, preferably a superflat with stone as the top layer.
2. unzip the zip file and place it into the datapacks folder of your world
3. leave and rejoin.

## In-Game Menu
Press G to open the in-game menu.

## How to Use
* The datapack will automatically give you all of the essential blocks, including wires and gates.
* Levers and buttons are inputs; place them next to a wire and turn it on.
* Wool blocks are logic gates. They should be named accordingly. To get an output from them, you must place an output carpet next to it, along with a wire to see the output.

## Recommended extenstions
* Axiom is highly recommended for use in building bigger circuits
